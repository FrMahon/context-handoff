# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**Security tab → "Report a vulnerability"** (private vulnerability reporting).

Do not open a public issue for security problems. I aim to reply within a few days.

## Scope

This plugin runs a hook and scripts on your machine. Reports about code
execution, unsafe file access or leaking of conversation data are in scope.

## Supported versions

Only the latest commit on `main` is supported.
